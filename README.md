## 👨‍💻 Project Overview

Welcome to my **Windows Server 2025 Administration Lab**, a hands-on technical project focused on developing practical skills in Windows Server deployment, system administration, networking, and centralized IT management.

Using **Oracle VirtualBox**, I deployed Windows Server 2025 in a virtualized environment and began configuring the foundational components required for server administration. The lab also explores Active Directory concepts, Organizational Units (OUs), and Group Policy Objects (GPOs).

This repository serves as a technical portfolio documenting my implementation process, configuration tasks, troubleshooting experience, and continued professional development in IT infrastructure.

> **Project focus:** Applying theoretical IT knowledge through practical implementation and structured technical documentation.

## 🏗️ Implementation Roadmap

### Phase 1 — Server Deployment

**Day 1: Windows Server 2025 Installation**

- Created a virtual machine in Oracle VirtualBox.
- Installed Windows Server 2025.
- Completed the initial operating system setup.
- Prepared the virtual machine for further configuration.

### Phase 2 — Initial Configuration

**Day 2: Server Configuration and Networking**

- Configured the server hostname: `Server2025-DC01`.
- Adjusted the system time zone using PowerShell.
- Configured a static IP address.
- Configured DNS settings in preparation for Active Directory.
- Installed available Windows updates.
- Verified network settings and connectivity using `ipconfig` and `ping`.

**Key takeaway:** Proper server identification, time configuration, network addressing, and DNS settings provide an important foundation for subsequent server roles and services.

### Phase 3 — Group Policy Administration

**Day 8: Group Policy Management**

- Created Group Policy Objects (GPOs).
- Linked GPOs to the Employees Organizational Unit and departmental OUs.
- Practised organizing policy assignments within the directory structure.
- Explored how Group Policy supports centralized administration of users and computers.

**Key takeaway:** Correct OU organization and GPO linking are important for applying administrative settings consistently to the intended users and computers.

*Additional milestones will be documented as the lab progresses.*
